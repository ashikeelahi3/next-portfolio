# Ashik E Elahi — Portfolio

Personal portfolio website built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS** and **Framer Motion**.

## Getting Started

```bash
# install dependencies (bun, pnpm or npm all work)
bun install

# start the dev server
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## SEO & Deployment Configuration

All canonical/OG/sitemap URLs derive from one value, resolved in this order:

1. `NEXT_PUBLIC_SITE_URL` — **optional**, only needed if you add a custom domain later (see `.env.example`)
2. `URL` — injected automatically by Netlify on every build
3. Hardcoded default: `https://ashikeelahi3.netlify.app`

So the site works out of the box on Netlify with zero configuration. Metadata lives in `src/app/layout.tsx`. The `sitemap.xml`, `robots.txt` and PWA `manifest.webmanifest` are generated by the App Router file conventions in `src/app/`.

## Production Build

```bash
bun run build
bun run start
```

## Tech Stack

- [Next.js 15](https://nextjs.org) (App Router) + React 19
- TypeScript
- Tailwind CSS (dark mode via `class`)
- Framer Motion animations
- Deployed on Netlify (`netlify.toml`)
